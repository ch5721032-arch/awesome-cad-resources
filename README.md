## CAD Software

### 2D CAD

- [AutoCAD](https://www.autodesk.com/products/autocad) - Industry-standard 2D and 3D CAD software by Autodesk.
- [GSTARCAD](https://www.gstarcad.net) - High-performance, cost-effective CAD software with full DWG compatibility. Powerful 2D drafting and 3D modeling capabilities, ideal as an AutoCAD alternative.
- [DraftSight](https://www.draftsight.com) - Professional 2D drafting and 3D design experience by Dassault Systèmes.
- [ZWCAD](https://www.zwcad.com) - Fast and reliable CAD software with strong DWG compatibility.
- [BricsCAD](https://www.bricsys.com) - Professional CAD with a familiar interface and AI-powered features.
- [NanoCAD](https://nanocad.com) - Free and professional CAD platform with native DWG support.
- [LibreCAD](https://librecad.org) - Free and open-source 2D CAD application (cross-platform).
- [QCAD](https://www.qcad.org) - Free and open-source 2D CAD for Windows, macOS, and Linux.

### 3D CAD

- [SolidWorks](https://www.solidworks.com) - Industry-leading 3D CAD for mechanical design.
- [Fusion 360](https://www.autodesk.com/products/fusion-360) - Cloud-based 3D CAD/CAM/CAE by Autodesk.
- [CATIA](https://www.3ds.com/products/catia) - Multi-platform CAD/CAM/CAE software suite.
- [Creo](https://www.ptc.com/en/products/creo) - Scalable 3D CAD solution for product design.
- [Inventor](https://www.autodesk.com/products/inventor) - Professional-grade 3D CAD for mechanical design.
- [NX (Siemens)](https://www.plm.automation.siemens.com/global/en/products/nx/) - Advanced CAD/CAM/CAE software.
- [Onshape](https://www.onshape.com) - Cloud-native 3D CAD with real-time collaboration.
- [FreeCAD](https://www.freecad.org) - Free and open-source parametric 3D modeler.
- [Blender](https://www.blender.org) - Free and open-source 3D creation suite (modeling, animation, rendering).

### Cloud-Based CAD

- [Onshape](https://www.onshape.com) - Pure cloud 3D CAD with version control and collaboration.
- [Fusion 360](https://www.autodesk.com/products/fusion-360) - Cloud-connected CAD/CAM/CAE.
- [SketchUp Free](https://www.sketchup.com) - Web-based 3D modeling for architecture and design.
- [Vectary](https://www.vectary.com) - Browser-based 3D design and collaboration.
- [Tinkercad](https://www.tinkercad.com) - Free, easy-to-use 3D CAD for beginners (by Autodesk).

## CAD File Converters & Utilities

- [Any DWG Converter](https://www.anydwg.com) - Batch DWG/DXF converter.
- [CADProps](https://www.cadprops.com/tools/step-viewer/) - Browser-based STEP viewer with geometry measurements and section views; viewing requires no account.
- [CloudConvert](https://cloudconvert.com/dwg-converter) - Online CAD file format converter.
- [DWG TrueView](https://www.autodesk.com/products/dwg-trueview) - Free DWG viewer and converter by Autodesk.
- [dxf2gcode](https://github.com/dxf2gcode/dxf2gcode) - Open-source tool to convert DXF to GCode for CNC.
- [ODA File Converter](https://www.opendesign.com/oda-file-converter) - Free converter for DWG, DGN, and DWF files.
- [Teigha File Converter](https://www.opendesign.com/teigha-file-converter) - DWG/DXF batch converter by Open Design Alliance.

## Libraries & SDKs

- [Open Design Alliance SDK](https://www.opendesign.com) - SDK for reading/writing DWG, DGN, and other CAD formats.
- [Teigha (ODA)](https://www.opendesign.com/teigha) - Development platform for CAD applications.
- [DXF Parser (Python)](https://github.com/mozman/ezdxf) - Pure Python library to read/write DXF files.
- [DWG/DXF Reader (JS)](https://github.com/joeaudette/DDX) - JavaScript library for parsing DXF files in the browser.
- [Three.js CAD Viewer](https://threejs.org) - 3D rendering library for building browser-based CAD viewers.
- [OpenCascade](https://www.opencascade.com) - 3D modeling and geometry kernel (open-source).
- [CADExchanger SDK](https://cadexchanger.com) - SDK for CAD data exchange and 3D visualization.
- [IfcOpenShell](https://ifcopenshell.org) - Open-source library for IFC (BIM) file format.

- [AutoCAD Tutorials (Autodesk)](https://knowledge.autodesk.com/support/autocad) - Official AutoCAD learning resources.
- [CADTutor](https://www.cadtutor.net) - Free tutorials, articles, and tips for CAD users.

## Open Source CAD

- [FreeCAD](https://www.freecad.org) - Parametric 3D CAD modeler (LGPL).
- [LibreCAD](https://librecad.org) - 2D CAD drawing platform (GPL).
- [QCAD](https://www.qcad.org) - 2D CAD for technical drawing (GPL).
- [OpenSCAD](https://openscad.org) - Programmatic 3D CAD (modeling through code).
- [SolveSpace](https://solvespace.com) - Parametric 2D/3D CAD (GPL).
- [BRL-CAD](https://brlcad.org) - Cross-platform solid modeling system (BSD).
- [HeeksCAD](https://github.com/Heeks/heekscad) - Open-source CAD/CAM application.
- [CadQuery](https://cadquery.readthedocs.io) - Python parametric 3D CAD modeling library.
